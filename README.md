# news-image

Entry for make.fun's "Sum up 23 November's world news in one image" bounty.

The image (`entry.png`) is a newspaper front page summing up the verified top
stories of Monday, 23 November 2026: Nvidia reinstates Jensen Huang as chief
executive, Ukraine's sea drones hit a Russian warship off Libya, Tajikistan
starts leaving the ICC, Puigdemont is free to return to Spain, the NHS
launches the world's largest AI cancer-scan trial, India pledges $1.62B to
rebuild Nepal, and Armenia drafts a new constitution.

`main.ts` copies `entry.png` into the output directory
(`MAKEFUN_OUTPUT_DIR`, default `/output`).
